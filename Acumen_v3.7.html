🧙 Ollama Setup Guide

Step 1: Install Ollama

Download from ollama.com and install for your OS.

Step 2: Pull a vision model

ollama pull gemma4:12b

Gemma4 (12B) recommended for genre-aware scoring with narrative output. Fits in RTX 3090 VRAM.

Step 3: Enable CORS (required for browser access)

Windows (Admin PowerShell):

[System.Environment]::SetEnvironmentVariable("OLLAMA_ORIGINS", "*", "Machine")

Then kill all Ollama processes and restart:

taskkill /f /im ollama.exe $env:OLLAMA_ORIGINS="*" $env:OLLAMA_NUM_PARALLEL="2" ollama serve

macOS/Linux:

OLLAMA_ORIGINS="*" OLLAMA_NUM_PARALLEL=2 ollama serve

Step 4: Verify

Click "Test" in Settings to confirm connectivity.

Performance Tips (RTX 3090 + 192GB RAM):

  • Set Parallel AI Requests to 2 (matches OLLAMA_NUM_PARALLEL=2)
  • Gemma4 12B uses ~10GB VRAM — leaves headroom for parallel inference
  • Expected speed: ~10-20 seconds per image with parallel=2
  • 3,500 images at 15s avg with parallel=2 ≈ 7.3 hours
  • Auto-save every 50 images prevents data loss
  • You can pause/resume at any time — progress is never lost
